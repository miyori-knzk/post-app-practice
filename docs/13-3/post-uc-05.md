#### UC-05: {投稿の編集をする}

- **アクター**: {ログイン済み利用者}
- **事前条件**: {ログイン状態である。ログイン済み利用者は投稿した本人である}
- **基本フロー**:
    1. ログイン済み利用者が投稿の一覧画面で、詳細を押下する。
    2. システムがタイトル、トピック、本文を表示する。
    3. ログイン済み利用者が、投稿のタイトル、トピック、本文を編集して、更新を「押下」する。
    4. システムが投稿を書き換え、投稿一覧画面へ戻す。
- **代替フロー**:
    - 1a. 他人の投稿の編集画面のURLを直接開いた場合：システムは編集画面を表示せず、権限がないことを伝える
    - 3a.　タイトルまたは本文が空の場合 : システムはエラーメッセージを表示し、投稿を書き換えない
- **事後条件**: 投稿の内容が書き換わり、投稿一覧画面に反映される
- **受け入れ条件**:
    - [ ] 投稿一覧画面で、自分の投稿にだけ、「編集」が表示される
    - [ ] 内容を書き換えて、「更新」を押すと、投稿一覧画面に書き換えた内容が表示される
    - [ ] タイトルを空にして「更新」を押すと、エラーメッセージが表示され、投稿の内容は変わらない
