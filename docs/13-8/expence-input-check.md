# 申請登録画面 入力チェック表

| 画面         | 項目 | 必須 | 文字数・桁数 | 形式・値の範囲                       | ほかの項目との関係 |
| :----------- | :--- | :--- | :----------- | :----------------------------------- | :----------------- |
| 投稿編集画面 | 使途 | 必須 | 255文字以内  | -                                    | -                  |
| 投稿編集画面 | 金額 | 必須 | 5桁          | 数字、5万円まで                      | -                  |
| 投稿編集画面 | 費目 | 必須 | -            | 交通費/書籍代/会議費/+その他から選択 | -                  |

タイトルの255文字は、決めて選んだ数字ではありません。laravelのデータベースを文字列で作った際のデフォルトの値です。申請一覧に並べたときに読みやすい長さを考えると、50文字や100文字にする案もあります。「255文字でで問題ないですか」と確認事項リストへ回します。
