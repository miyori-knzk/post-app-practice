# API設計書

## エンドポイント一覧

| ID     | メソッド | エンドポイント      | 何をするか           | 認証 |
| :----- | :------- | :------------------ | :------------------- | :--- |
| API-01 | GET      | /api/requests/index | 申請一覧の表示       | 必要 |
| API-02 | POST     | /api/requests       | 申請の登録           | 必要 |
| API-03 | GET      | /api/requests/{id}  | 申請編集画面の表示   | 必要 |
| API-04 | PUT      | /api/requests/{id}  | 申請の更新           | 必要 |
| API-05 | GET      | /api/approve/index  | 承認一覧の表示       | 必要 |
| API-06 | GET      | /api/approve/{id}   | 承認詳細の表示       | 必要 |
| API-07 | PUT      | /api/approve/{id}   | 承認・差し戻しの登録 | 必要 |

#### API-02: 申請を登録する

- **メソッドとエンドポイント**: POST /api/requests
- **認証**: 必要
- **送るもの**: 本文で、立替日・金額（5万円まで）・使途・費目（交通費/書籍代/会議費/その他）を入れる
- **返すもの（うまくいったとき）**: 201。立替日・金額（5万円まで）・使途・費目（交通費/書籍代/会議費/その他）を返す。
- **返すもの（うまくいかなかったとき）**: 422（送ったものに不備があるとき）

#### API-02: 承認の登録をする

- **メソッドとエンドポイント**: PUT /api/approve/{id}
- **認証**: 必要
- **送るもの**: 承認
- **返すもの（うまくいったとき）**: 201。立替日・金額（5万円まで）・使途・費目（交通費/書籍代/会議費/その他）・承認ステータスを返す。
- **返すもの（うまくいかなかったとき）**: 404（見つからなかったとき）

## エラーレスポンス一覧

| 起きること                             | ステータスコード | 返すもの                           |
| :------------------------------------- | :--------------- | :--------------------------------- |
| 自分の申請でない(取得・修正)           | 403              | 権限がない旨の文言                 |
| 指定した申請が見つからない(取得・修正) | 404              | 見つからない旨の文言               |
| 送ったものに不備がある(修正・作成)     | 422              | 不備のあった項目と、その理由の文言 |
| 承認者でない(取得・承認・差し戻し)     | 403              | 権限がない旨の文言                 |
