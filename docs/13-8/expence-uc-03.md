#### UC-03: 申請の承認をする

- **アクター**: 承認者
- **事前条件**: 経費の申請がされている
- **基本フロー**:
    1. 承認者が、申請一覧画面から対象の申請を選ぶ
    2. システムが、立替日、金額、使途、費目を表示する
    3. 承認者が、承認ボタンを押下する
    4. システムが、承認済みとして登録する
    5. システムが、申請一覧画面を表示する
- **代替フロー**:
    - 3a. 差し戻しとした場合：システムは承認済みとして登録せず、差し戻しの理由が表示され、申請者が再度申請できるようになる
- **事後条件**: 申請が承認済みとなる。
- **受け入れ条件**:
    - [ ] 対象の申請を選ぶと、立替日、金額、使途、費目が表示される
    - [ ] 承認されると、承認済みとして登録される
    - [ ] 差し戻しとすると、承認済みとして登録されず、差し戻しの理由が表示され、申請者が再度申請できるようになる
