# 申請登録画面 画面項目定義

| 項目名         | 種類         | 必須 | 内容                                                                                                               |
| :------------- | :----------- | :--- | :----------------------------------------------------------------------------------------------------------------- |
| 画面見出し     | 表示         | -    | 「申請登録画面 」                                                                                                  |
| 立替日         | 入力         | 必須 | 立替日の入力。開いたときは今日の日付入っている。差し戻しされた申請の再申請時には初回の申請の日付が入力されている。 |
| 金額           | 入力         | 必須 | 立替金額の入力。差し戻しされた申請の再申請時には初回の申請の日付が入力されている。                                 |
| 使途           | 入力（一行） | 必須 | 使途の入力。 差し戻しされた申請の再申請時には初回の申請の使途が入力されている。                                    |
| 費目           | 選択         | 必須 | 費目の選択。差し戻しされた申請の再申請時には初回の申請の費目が入力されている。                                     |
| 更新ボタン     | ボタン       | -    | 押すと書き換えを保存し、投稿一覧画面へ移る                                                                         |
| 申請一覧に戻る | リンク       | -    | 押すと保存せずに申請一覧画面へ移る                                                                                 |
