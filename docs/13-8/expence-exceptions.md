# 例外一覧

| 起きること         | どこで気づくか                           | その時の処置    | 利用者への知らせ               |
| :----------------- | :--------------------------------------- | :-------------- | :----------------------------- |
| 　該当の申請がない | 申請を表示しようとしたとき               | 404エラーを出す | 申請がない旨のメッセージを表示 |
| 　該当の申請がない | 差し戻しの申請を再申請しようとしたとき   | 404エラーを出す | 申請がない旨のメッセージを表示 |
| 　該当の申請がない | 申請待ちの申請を承認しようとしたとき     | 404エラーを出す | 申請がない旨のメッセージを表示 |
| 　該当の申請がない | 申請待ちの申請を差し戻ししようとしたとき | 404エラーを出す | 申請がない旨のメッセージを表示 |
